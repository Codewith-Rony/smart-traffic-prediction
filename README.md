# 🚦 Smart Traffic Flow Prediction and Signal Control System

A machine learning-based traffic prediction system developed during my **AI & ML Internship at Unique World Robotics**. The project analyzes traffic data to predict vehicle flow and demonstrates how machine learning can support intelligent traffic signal management.

The solution was built using Python and Scikit-learn, with data preprocessing, model training, evaluation, and visualization performed in Jupyter Notebook.

---

## 📖 Overview

Urban traffic congestion is a growing challenge that leads to increased travel time, fuel consumption, and pollution. This project explores how machine learning can be used to analyze historical traffic data and predict traffic flow, enabling smarter signal control decisions.

The project was completed as part of my internship at **Unique World Robotics**, where I gained practical experience in data preprocessing, regression models, model evaluation, and visualization techniques.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Codewith-Rony/smart-traffic-flow-prediction.git
```

### Navigate to the project

```bash
cd smart-traffic-flow-prediction
```

### Install dependencies

```bash
pip install -r requirements.txt
```

> If a `requirements.txt` file is not available, install the required libraries manually:

```bash
pip install pandas numpy matplotlib scikit-learn streamlit
```

### Run the notebook

Open the notebook using Jupyter Notebook or JupyterLab.

```bash
jupyter notebook
```
